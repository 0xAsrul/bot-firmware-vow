A single wedding vow for a robot: one sentence, under 200 characters, that a machine says at its own wedding — funny and heartfelt at the same time.

## Run it

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
